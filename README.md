# 🗺️ Интерактивный географический атлас и система тестирования Ростовской области

Веб-приложение разработано в рамках дипломного проекта и представляет собой интерактивный картографический комплекс на базе **Python**, **Geopandas**, **Folium** и **FastAPI**. Проект предназначен для изучения физической и административной географии Ростовской области, а также для проверки пространственных знаний студентов с помощью геймифицированных тестов.

---

## 🚀 Основные возможности

* **Интерактивная карта (Folium / Leaflet)**:
  * Отображение административных границ районов, гидрографии (рек и водоемов) и административных центров.
  * Динамические всплывающие подсказки и информационные карточки при клике на районы (население, площадь, соседние территории).
* **Система тестирования (Викторины)**:
  * *«Угадай район по очертаниям»* — проверка визуального распознавания границ.
  * *«Районы-соседи»* — проверка знаний топологических связей и смежности территорий.
  * *«Угадай реку по руслу»* — гидрографический тест с интерактивной подсветкой водных объектов.
  * *«Найди райцентр на карте»* — координатный тест на точность клика с автоматическим расчетом погрешности в километрах.
* **Авторизация студентов ЮФУ**:
  * Вход через корпоративную почту (`@sfedu.ru`) с одноразовой верификацией по коду.
* **Центр успеваемости и таблица лидеров**:
  * Глобальный топ студентов с гибкой фильтрацией по категориям тестов.
  * Личный профиль пользователя с сохранением лучших результатов и подробной историей прохождений (баллы, точность в процентах, затраченное время).

---

## 🛠️ Технологический стек

* **Бэкенд**: Python, FastAPI, Uvicorn, Pydantic
* **ГИС и картография**: GeoPandas, Shapely, Folium (Leaflet.js)
* **Фронтенд**: HTML5, CSS3, JavaScript (встроенная интерактивная логика)
* **Инфраструктура**: SMTP (Yandex Mail) для отправки кодов верификации

## ⚙️ Установка и локальный запуск

Для работы проекта необходим установленный **Python версии 3.8 или выше**.

### 1. Клонирование репозитория и настройка окружения
```bash
git clone https://github.com/твой-аккаунт/rostov-geo-quiz.git
cd rostov-geo-quiz
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или venv\Scripts\activate для Windows

pip install -r requirements.txt
```

### 3. Генерация карты и запуск
Сначала сгенерируйте интерактивную ГИС-карту на основе пространственных данных:
```bash
python main.py
```

Запустите сервер веб-приложения:
```bash
python server.py
```

После этого приложение станет доступно в браузере по адресу: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**.
